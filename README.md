Entry for the make.fun competition [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8) — exactly one word.

## The entry

> Snickerdoodle

Three candidates were compared against the judge's brief (exactly one word, surprising, vivid and specific, a spark of wit or sound that rewards a second look, chosen rather than generic). This one won: it names one specific cookie, its sound is inherently funny, and it hides a second reward — "snicker" sitting inside it. The alternatives ("Pumpernickel", also specific but only a sound joke, and "Kerfuffle", witty but abstract with no image) each missed one of those layers.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed word to `entry.txt`, validates 1–24 characters and exactly one word, and reads the file back byte for byte. Running it twice produces identical bytes (sha256 ca5e5a62785c11623848bc0a06a75e8a6585126b03189ec6dc6159120fd56602).
